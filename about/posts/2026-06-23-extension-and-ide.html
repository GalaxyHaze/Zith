Two Editors, One Language Server

2026-06-23

With the LSP answering queries, the question becomes what talks to it. This week that was two things: the VS Code extension, which needed fixing, and a standalone IDE, which needed starting.

VS Code

The Zith extension has been updated on the marketplace. The real bug was the binary download pipeline — download-lsp.js now pulls the correct platform-specific build from CI artifacts and the extension finds it at startup instead of silently doing nothing.

Syntax highlighting, snippets and the "Zith Dark" theme are stable. The TextMate grammar covers the newer keywords (component, union, scene, spawn) and the snippets match current function, struct and control-flow syntax.

Zith-Studio

The other experiment is a small standalone IDE — placeholder name Zith-Studio — aimed at being lighter than VS Code with deeper language integration. The target is zero config: open a .zith file, get highlighting, inline diagnostics from the LSP and a run command, with no project scaffolding in between.

It is early. The repository is at GalaxyHaze/Zith-Studio if you want to watch it take shape.
