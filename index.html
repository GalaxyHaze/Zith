Why Zith and Zith--?

Zith explores deterministic ownership; the current compiler supports its sibling language, Zith--.

Zith Ownership Design

Zith specifies Node Resource Analysis (NRA) for static ownership and lifetime proofs. The current zithc compiler implements sibling Zith--, which has a separate, frozen ownership analysis called SRA (Small Resource Analysis).

Native Compiler for Zith--

The zithc compiler lowers supported Zith-- programs through LLVM to native code or WebAssembly, with direct memory layout and no garbage collector.

Language and Tooling Ecosystem

The project develops zithc for Zith-- alongside language server tools (zith-lsp), the browser IDE (Glarea), an interactive playground, and cross-platform installation scripts.
