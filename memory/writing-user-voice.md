# User's Positioning-Writing Style

When helping edit the user's language-positioning prose, preserve its direct,
contrast-led voice. The user states each language's goal, explains the
difference, and helps readers choose based on what they value. Concrete
examples support the reasoning, but do not automatically belong in the concise
public-facing summary.

## Editing Guidance

- Keep the user's thesis and distinction between Zith and `Zith--` explicit.
- Prefer clear claims about goals and tradeoffs over generic promotional language.
- Preserve reader-oriented choices such as "choose this if you care about..."
- Use examples to clarify the intended meaning during discussion; include them
  in the final positioning copy only when they improve the reader's decision.
- Polish grammar and ambiguity without replacing the user's structure or voice.
- Keep public documentation in its draft language unless the user asks for a
  translation.
