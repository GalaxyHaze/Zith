Types

Zith has signed and unsigned integer types, floating-point types, bool, and char. Structs, components, enums, and unions are working core declarations.

struct Point {
    x: i32,
    y: i32,
}

enum Direction { North, South, East, West }

Start with explicit annotations when learning. The Type System reference defines arrays, slices, generic types, unions, and the experimental narrowing rules.
