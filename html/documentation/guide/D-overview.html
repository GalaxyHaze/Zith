Language Guide

This guide is the practical entry point to Zith. The main compiler builds the Zith-- subset documented in the Zith-- reference; Zith-spec remains the larger specification ahead of implementation.

Start with working features

Read Syntax, Bindings, Types, Functions, and Control Flow first. These topics cover working Zith-- functionality.

Check experimental features

Memory Model, Errors, Comptime, Contexts, Words & Macros, and Concurrency include specification material that is not fully implemented. Each page points to the current status.
