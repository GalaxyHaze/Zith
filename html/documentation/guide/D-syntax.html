Syntax

Zith source uses braces for blocks and semicolons for ordinary statements. A function body may end with an expression, which becomes its return value.

fn add(a: i32, b: i32): i32 {
    a + b
}

Use // for a line comment. Write a declaration before its use, and keep the first programs within the working core. See Functions and the formal Function reference.
