Generics

Generic declarations use angle brackets. Simple monomorphization is working.

struct Pair<T, U> {
    first: T,
    second: U,
}

Complex constraints are only partially implemented. Keep early code to simple type parameters and verify the result with zithc check. The complete syntax is in the Type System reference.
