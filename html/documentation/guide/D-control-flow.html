Control Flow

if, when, and for are working control-flow constructs. Use if for a boolean branch and for for iteration.

fn sign(value: i32): i32 {
    if (value < 0) {
        -1
    } else {
        1
    }
}

The language also specifies chains, markers, docks, and jumps. The latter are specialized tools; consult the Control Flow reference before using them.
