Traits & Interfaces

Traits and interfaces declare behavior contracts; implementation blocks attach methods and trait implementations to a type.

trait Printable {
    fn print(self);
}

Declarations parse and resolve, while advanced dispatch and capability semantics have implementation limits. Consult Implementation Status and the Traits & Interfaces reference.
