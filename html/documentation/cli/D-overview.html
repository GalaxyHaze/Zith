CLI Reference

This reference documents the working zithc commands recorded in the canonical implementation status dated July 15, 2026. Command options change with the compiler; use zithc --help for the executable you installed.

Working commands

  • zithc build
  • zithc run
  • zithc check
  • zithc fmt
  • zithc create
  • zithc clean
  • zithc execute

test, repl, and deps exist as Stub commands and are intentionally not documented as active workflows.
