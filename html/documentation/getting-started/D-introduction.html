Introduction

Zith is a statically typed compiled language with a specification that is ahead of its implementation. This portal is therefore language documentation in draft form, not a stability guarantee.

Read the right document

  • Start with Quick Start to create and run a project.
  • Use the Language Guide for short practical explanations.
  • Use the Language Reference for the canonical specification.
  • Check Implementation Status before using a feature in production code.

The compiler currently supports core declarations, bindings, control flow, modules, generics, and C interop. Ownership analysis, async execution, and context-based extensions remain experimental or specification-only.
