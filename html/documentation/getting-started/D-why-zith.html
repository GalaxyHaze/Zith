Why Zith

Zith explores a systems-language design that combines a small everyday core with explicit tools for domain-specific work. The design includes modules, typed functions, algebraic data types, traits, C interop, compile-time facilities, and a planned ownership model.

The distinction matters: the Specification describes the intended language, the Zith-- reference is the implemented subset compiled by main, and Implementation Status records feature-by-feature what zithc can compile today.
