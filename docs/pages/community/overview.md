# Community

Use the Zith issue tracker for compiler bugs and language discussions. Report the compiler version, command line, source sample, expected behavior, and actual diagnostics.

Documentation contributions should distinguish specification text from observed implementation behavior. The specification belongs in `../Zith/docs`; site editorial content belongs in this repository's `docs/pages`.
