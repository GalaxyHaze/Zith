# Memory Model

The specification defines Node Resource Analysis (NRA) and modifiers such as `lend`, `view`, `unique`, `share`, and `belong`. The compiler's NRA pass is currently **Spec only**.

Do not present ownership examples as compiler-enforced behavior yet. Read the [Memory Model reference](doc:reference-07-memory-model) for the design and [Implementation Status](doc:reference-implementation-status) for the implementation boundary.
