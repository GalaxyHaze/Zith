# Why Zith

Zith explores a systems-language design that combines a small everyday core with explicit tools for domain-specific work. The design includes modules, typed functions, algebraic data types, traits, C interop, compile-time facilities, and a planned ownership model.

The distinction matters: the [Specification](doc:reference-specification) describes the intended language, while [Implementation Status](doc:reference-implementation-status) states what `zithc` can compile today. Treat the latter as the operational source of truth.
